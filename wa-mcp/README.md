# wa-mcp CLI (`wa`)

Typer CLI for the wa-mcp product family. `pip install wa-mcp` → `wa`. MCP server: `mac-wa-mcp` → `wa-mcp`.

Every command and command group accepts `-h`/`--help`. Root help lists the
command hierarchy without generated shell-completion flags; use `-V` or
`--version` to print the installed CLI version.
